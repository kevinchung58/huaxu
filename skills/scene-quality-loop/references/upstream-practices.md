# Upstream agent-skill survey (2026-10-17)

Research question: how current agent `SKILL.md` projects turn game/3D briefs into complete environments, and which parts transfer to Huaxu's grounded walkable places. Sources below were read at the pinned commit shown in each URL. Licenses and repository-specific constraints were checked before deciding what to adopt. This is a method/provenance note, not a dependency list; no upstream skill file, script, starter, or generated asset is copied into the runtime.

## Resulting Huaxu workflow

`scene-system` routes scope and evidence → `real-place-builder` plus `grounded-scene` and the matching domain skill author the place → `scene-quality-loop` captures and reads the actual route/object frames → PUA diagnoses and verifies each repair → `pr-handoff` updates the complete next-round `TODO.md` plan before any PR is opened or updated. The existing Three.js 0.186.1 pin, Canvas2D fallback, no-CDN/no-new-runtime-dependency rule, and Activities-album boundary remain unchanged.
