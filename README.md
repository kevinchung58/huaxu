# Hua-Xu Zhong — Academic Portfolio

Personal academic site for Dr. Hua-Xu Zhong (鍾華栩).  
Live: https://kevinchung58.github.io/huaxu

## Stack

React 19, TypeScript, Vite, Tailwind CSS v4, HashRouter (GitHub Pages).

## Design

Visual system generated with [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill):

- Style: Soft UI Evolution (education-tech warmth + HCI-lab clarity)
- Palette: scholarly navy `#1E3A5F` + citation gold `#B45309`
- Type: Crimson Pro (headings) + Atkinson Hyperlegible (body)
- Source of truth: `design-system/hua-xu-zhong/MASTER.md`
- Agent workflow: `AGENTS.md` → `.agents/skills/`

## Develop

```bash
npm install
npm run dev
```

Production base path is `/huaxu/`. Images live in `public/IMG/`.
